Kebijakan Privasi

Dinta Report Assistant · berlaku sejak 22 Oktober 2026

Ringkasan

Dinta Report Assistant adalah aplikasi desktop. Data Anda diproses di komputer Anda sendiri. Pengembang tidak mengumpulkan, menyimpan, atau menerima data Anda di server mana pun.

Data yang diproses di komputer Anda

  • Screenshot yang Anda tambahkan, beserta teks yang dibaca dari screenshot (OCR) — untuk menyarankan nama aktivitas.
  • Nama aktivitas, tanggal, dan task yang Anda pilih — untuk menulis file Excel Log Aktivitas Harian di komputer Anda.
  • Profil (nama, rumpun, level, squad, platform) yang Anda isi.

Data ini disimpan di folder data aplikasi pada komputer Anda dan dapat Anda hapus kapan saja.

Data Google (bila Anda masuk dengan akun Google)

  • Alamat email akun Google Anda — hanya untuk menampilkan akun yang tersambung.
  • Akses drive.file — aplikasi hanya dapat mengakses folder dan Google Sheet yang Anda pilih sendiri melalui Google Picker, serta file yang dibuat aplikasi. Aplikasi memakai akses ini untuk: (1) mengunggah screenshot bukti kerja ke folder yang Anda pilih, dan (2) membaca serta menambahkan baris log aktivitas ke Google Sheet yang Anda pilih.
  • Token login disimpan di penyimpanan aman sistem operasi (Keychain macOS / penyimpanan kredensial Windows) dan hanya dipakai untuk menghubungi Google atas nama Anda.
  • Data Google tidak dikirim ke pihak lain, tidak dijual, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI.

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh aplikasi ini mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

Fitur AI di perangkat

Di Mac yang mendukung Apple Intelligence, saran nama aktivitas dapat dibuat oleh model bahasa yang berjalan di perangkat. Teks screenshot tidak dikirim ke internet untuk fitur ini.

Mencabut akses

Anda dapat keluar dari akun Google di Pengaturan aplikasi kapan saja, atau mencabut akses melalui myaccount.google.com/permissions.
