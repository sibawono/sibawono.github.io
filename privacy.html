Kebijakan Privasi

Dinta Report Assistant (macOS & Windows) · berlaku sejak 29 Oktober 2026 · menggantikan versi 22 Oktober 2026

Ringkasan

  • Dinta Report Assistant adalah aplikasi desktop. Screenshot, teks hasil OCR, daftar aktivitas, dan profil Anda diproses dan disimpan di komputer Anda sendiri.
  • Data hanya keluar dari komputer Anda ke layanan yang Anda sambungkan sendiri — Google (Drive & Sheets), Talenta (presensi, khusus Mac) — dan ke Layanan Data DINTA untuk mengambil daftar task dan daftar Tenaga Ahli.
  • Pengembang tidak menyimpan data pribadi Anda di server, tidak memasang analitik, pelacak, atau iklan, tidak menjual data, dan tidak memakai data Anda untuk melatih model AI.
  • Anda dapat memutus setiap sambungan dan menghapus seluruh data aplikasi kapan saja (lihat Penyimpanan & penghapusan).

1. Pengelola & ruang lingkup

Dinta Report Assistant dikembangkan dan dikelola oleh Anggi Waskitaning Bawono (selanjutnya “pengembang” atau “kami”) sebagai alat bantu bagi Tenaga Ahli untuk menyusun screenshot bukti kerja dan Log Aktivitas Harian. Aplikasi ini bukan produk resmi Google, Mekari/Talenta, maupun Slack.

Kebijakan ini berlaku untuk aplikasi Dinta Report Assistant untuk macOS dan Windows serta situs ini. Beberapa fitur hanya ada di Mac; fitur tersebut ditandai Mac.

Aplikasi ditujukan untuk akun kerja: login Google hanya diterima untuk akun domain teknologi.belajar.id. Akun Google lain ditolak dan tidak disimpan.

3. Data di komputer Anda

  • Screenshot yang Anda tambahkan. Aplikasi membuat salinan terkompresi (±1 MB) di folder bulan di dalam Folder Induk yang Anda pilih, lalu me-rename salinan itu sesuai format MM-DD_Nama Aktivitas setelah Anda mengonfirmasi tiap file. File asli Anda tidak diubah.
  • Teks di dalam screenshot dibaca dengan OCR bawaan sistem operasi (tanpa internet) untuk menyarankan nama aktivitas dan tanggal. Bila terbaca nomor HP, aplikasi hanya menyimpan jenis temuannya (“nomor HP”) untuk memberi peringatan, bukan nomornya.
  • Nama aktivitas, tanggal, task, dan status kirim — disimpan sebagai riwayat dan, bila Anda aktifkan, ditulis ke file Excel Log Aktivitas Harian di komputer Anda.
  • Profil yang Anda isi atau pilih: nama, rumpun, level, squad, platform.
  • Pola nama dari rename yang Anda konfirmasi (judul, kategori, kata kunci, jumlah pemakaian) agar saran berikutnya lebih tepat.
  • Pengaturan aplikasi (folder pilihan, tautan Google Sheet, jadwal pengingat, tampilan).
  • Bila Google Drive for desktop terpasang, aplikasi hanya membaca daftar folder Google Drive di Finder/File Explorer untuk menemukan folder laporan Anda; aplikasi tidak mengubah apa pun di sana kecuali menyalin screenshot ke folder laporan yang Anda pilih.

Lokasi folder data aplikasi:

  • macOS: ~/Library/Application Support/id.dinta.ReportAssistant/
  • Windows: %LOCALAPPDATA%\Dinta Report Assistant\

4. Akun Google, Drive & Sheets

Login Google bersifat opsional, tetapi diperlukan untuk sinkronisasi ke Drive/Sheet dan untuk mengambil daftar task. Aplikasi meminta izin (scope) berikut — tidak lebih:

  • openid dan email — mengetahui alamat email akun Anda untuk menampilkan akun yang tersambung dan memastikan akun berasal dari domain kantor. Aplikasi tidak meminta nama, foto, atau kontak Anda.
  • drive.file — aplikasi hanya dapat mengakses folder dan Google Sheet yang Anda pilih sendiri melalui Google Picker, serta file yang dibuat oleh aplikasi. Aplikasi tidak dapat melihat file Google Drive Anda yang lain.

Apa yang dilakukan aplikasi dengan akses ini

  • Mengunggah screenshot bukti kerja (yang sudah di-rename) ke folder Drive pilihan Anda.
  • Membaca isi Google Sheet laporan pilihan Anda untuk mengetahui baris yang sudah ada, lalu menambahkan/memperbarui baris log aktivitas (tanggal, nama aktivitas, task, tautan bukti, dan kolom profil).
  • Membaca daftar task dari Google Sheet yang tautannya Anda masukkan di Pengaturan. Di Windows, Sheet yang dibagikan lewat tautan dapat dibaca tanpa login (format CSV hanya-baca).
  • Folder dan Sheet tersebut biasanya berada di Shared drive kantor; orang lain yang memiliki akses ke folder itu (mis. admin/pengelola laporan) dapat melihat screenshot dan log yang Anda unggah, sesuai pengaturan berbagi di Google Drive, bukan pengaturan aplikasi.

Token & penyimpanan

  • Login memakai OAuth 2.0 dengan PKCE di browser sistem; kata sandi Google Anda tidak pernah dilihat aplikasi.
  • Refresh token disimpan di Keychain macOS, atau di Windows dalam file yang dienkripsi DPAPI (terkunci ke akun Windows Anda). Access token hanya disimpan di memori.
  • Saat Anda keluar dari akun Google di Pengaturan, token dicabut di Google dan dihapus dari komputer.

Kepatuhan terhadap kebijakan data pengguna Google

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh aplikasi ini mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use. Secara khusus, data Google Anda:

  • hanya dipakai untuk menyediakan fitur yang terlihat di aplikasi dan dijelaskan di halaman ini;
  • tidak dipindahkan ke pihak lain, kecuali bila perlu untuk menjalankan fitur tersebut, untuk keamanan, atau bila diwajibkan hukum;
  • tidak dipakai untuk iklan, tidak dijual, dan tidak dipakai untuk menilai kelayakan kredit;
  • tidak dibaca oleh manusia, kecuali dengan persetujuan Anda (mis. Anda sendiri mengirim log diagnostik), untuk keamanan, atau bila diwajibkan hukum;
  • tidak dipakai untuk mengembangkan, meningkatkan, atau melatih model AI/ML umum.

5. Layanan Data DINTA

Daftar task (dari file master task terbaru) dan daftar Tenaga Ahli tidak dibundel di dalam aplikasi; keduanya diambil dari Layanan Data DINTA, yaitu layanan kecil milik pengembang yang berjalan di Cloudflare Workers dan diisi otomatis dari Google Apps Script milik admin.

  • Yang dikirim aplikasi: ID token Google Anda (berisi alamat email, ID akun Google, dan masa berlaku) agar layanan dapat memastikan Anda memakai akun teknologi.belajar.id. Di versi macOS saat ini, token akses login juga ikut terkirim di header permintaan; layanan tidak memakai maupun menyimpannya.
  • Yang diterima aplikasi: daftar task, serta daftar Tenaga Ahli berisi nama, rumpun, level, kategori, platform, dan squad (tanpa email) untuk membantu Anda mengisi profil.
  • Yang disimpan layanan: hanya salinan daftar task dan daftar Tenaga Ahli. Layanan tidak menyimpan token, email, atau data aktivitas Anda. Sebagai penyedia infrastruktur, Cloudflare dapat mencatat data teknis permintaan (mis. alamat IP dan waktu) sesuai kebijakannya.
  • Aplikasi Windows saat ini tidak memakai layanan ini.

6. Talenta (presensi & cuti) Mac

Bila Anda menyambungkan Talenta (Mekari), Anda login sendiri di jendela Talenta di dalam aplikasi.

  • Aplikasi tidak pernah melihat atau menyimpan kata sandi Talenta Anda.
  • Agar tetap login setelah aplikasi ditutup, cookie sesi khusus domain talenta.co/mekari.com disimpan di Keychain macOS dan tidak dipulihkan bila lebih dari 7 hari. “Putuskan” menghapusnya.
  • Aplikasi membaca dari Talenta: ID karyawan, nama perusahaan, jadwal & jam clock-in/clock-out, kode kehadiran, cuti yang diambil, saldo cuti, dan status pengajuan koreksi absen. Data ini disimpan di komputer Anda untuk menampilkan presensi, menandai hari yang belum lengkap, dan memberi pengingat.
  • Pengajuan cuti/koreksi absen tetap Anda lakukan sendiri di halaman Talenta. Data Talenta tidak dikirim ke Google, ke pengembang, atau ke pihak lain.
  • Catatan teknis sinkronisasi (talenta-sync.log) disimpan di folder data aplikasi untuk membantu memecahkan masalah.

7. Kalender Mac

Dengan izin Anda, aplikasi membaca agenda dari kalender yang Anda pilih di macOS (mis. akun Google di Internet Accounts) untuk mencocokkan jam screenshot dengan meeting dan memakai judul meeting sebagai saran nama aktivitas. Aplikasi tidak membuat, mengubah, atau menghapus event, dan tidak mengirim agenda ke mana pun. Izin dapat dicabut di Pengaturan Sistem › Privasi & Keamanan › Kalender.

8. Lokasi Mac

Lokasi hanya diminta saat Anda membuka Live Attendance Talenta di dalam aplikasi, dan diberikan ke halaman Talenta agar Talenta dapat mencatat clock-in/clock-out Anda — sama seperti membuka Talenta di browser. Aplikasi tidak menyimpan lokasi. Izin dapat dicabut di Pengaturan Sistem › Privasi & Keamanan › Layanan Lokasi.

9. Fitur AI di perangkat Mac

Di Mac dengan macOS 26 atau lebih baru dan Apple Intelligence aktif, saran nama aktivitas dapat dipertajam oleh model bahasa Apple yang berjalan sepenuhnya di perangkat. Teks screenshot tidak dikirim ke internet atau ke penyedia AI mana pun. Bila Apple Intelligence tidak tersedia, aplikasi memakai kamus dan riwayat lokal saja. Aplikasi Windows tidak memakai AI.

10. Pemeriksaan pembaruan Mac

Aplikasi memeriksa versi terbaru ke GitHub (api.github.com) dan mengunduh pembaruan dari GitHub bila Anda setuju. Permintaan ini tidak membawa identitas atau data Anda; seperti setiap koneksi internet, GitHub dapat melihat alamat IP dan jenis aplikasi.

11. Log diagnostik

Menu “Kirim Log Diagnostik” membuat file .zip di komputer Anda berisi versi aplikasi, status izin, pengaturan, jumlah aktivitas per status, dan log teknis. File ini tidak berisi screenshot, cookie, token, data presensi, atau daftar aktivitas; alamat email dan angka panjang (mis. ID karyawan) disamarkan. File tidak dikirim otomatis — hanya Anda yang memutuskan untuk mengirimkannya ke pengembang.

12. Yang tidak kami lakukan

  • Tidak ada analitik, telemetri, pelacak, atau pelaporan crash otomatis.
  • Tidak ada iklan dan tidak ada penjualan atau penyewaan data.
  • Tidak ada pengiriman screenshot atau teks OCR ke server pengembang atau penyedia AI.
  • Tidak ada pengiriman otomatis tanpa tindakan Anda: rename dikonfirmasi per file, dan jenis aktivitas serta pengiriman laporan tetap Anda pilih sendiri.

13. Pihak ketiga

Data yang Anda kirim ke layanan berikut juga diatur oleh kebijakan privasi masing-masing:

  • Google (Drive, Sheets, login, Picker) — policies.google.com/privacy
  • Mekari Talenta — talenta.co
  • Cloudflare (Layanan Data DINTA) — cloudflare.com/privacypolicy
  • GitHub (pembaruan aplikasi & situs ini) — GitHub Privacy Statement
  • Apple (OCR, Kalender, Apple Intelligence di perangkat) — apple.com/legal/privacy

Situs ini adalah halaman statis di GitHub Pages tanpa cookie, formulir, atau skrip analitik.

14. Penyimpanan & penghapusan

Data lokal disimpan selama aplikasi terpasang dan tidak dihapus otomatis, agar riwayat laporan bulanan tetap ada. Cara menghapus:

  • Google: keluar di Pengaturan aplikasi (token dicabut & dihapus), atau cabut akses di myaccount.google.com/permissions. File yang sudah diunggah ke Drive/Sheet tetap ada di Drive dan dikelola dari Google Drive.
  • Talenta: tekan “Putuskan” di aplikasi untuk menghapus cookie sesi.
  • Kalender & Lokasi: cabut izin di Pengaturan Sistem macOS.
  • Semua data aplikasi: tutup aplikasi lalu hapus folder data di atas (§3); di macOS, hapus juga entri “Dinta”/“id.dinta.ReportAssistant” di aplikasi Keychain Access. Salinan screenshot di Folder Induk adalah file Anda dan dapat dihapus seperti file biasa.

15. Keamanan

  • Semua koneksi ke Google, Talenta, Layanan Data DINTA, dan GitHub memakai HTTPS.
  • Token dan cookie disimpan di penyimpanan aman sistem operasi (Keychain / DPAPI), bukan di file biasa.
  • Layanan Data DINTA memverifikasi tanda tangan ID token Google dan hanya melayani akun domain kantor; aplikasi tidak memuat kunci rahasia layanan.
  • Aplikasi Mac ditandatangani kode (code-signed) dengan Hardened Runtime.

Tidak ada sistem yang sepenuhnya aman. Bila kami mengetahui insiden yang memengaruhi data Anda, kami akan memberi tahu pengguna yang terdampak secepatnya.

16. Hak Anda

Sesuai Undang-Undang No. 27 Tahun 2022 tentang Pelindungan Data Pribadi, Anda berhak memperoleh informasi, mengakses, memperbaiki, menghapus, menarik persetujuan, dan mengajukan keberatan atas pemrosesan data pribadi Anda. Karena hampir semua data ada di komputer Anda, sebagian besar hak ini dapat Anda jalankan langsung di aplikasi (§14). Untuk hal lain — termasuk data Anda di daftar Tenaga Ahli Layanan Data DINTA — hubungi kami (§18).

Aplikasi ditujukan untuk tenaga kerja dewasa dan tidak ditujukan untuk anak di bawah 18 tahun.
